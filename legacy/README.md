# Legacy

Reference copies of the originals Shockr is rebuilt from. Not part of the build, not maintained,
and **not in git** (`.gitignore`): they are not ours to redistribute. Place them here after cloning.

- `shockr-tools-v4.5.3.6.user.js` — the original Shockr Tools webpack bundle (NetquiK [SoO] fork).
- `TA_Tiberium_Alliances_Battle_Simulator_V2.user.js` — TABS V2 23.05.31 (Eistee, TheStriker, VisiG,
  Lobotommi, XDaast; changes by NetquiK), from
  https://raw.githubusercontent.com/netquik/CnCTA-SoO-SCRIPT-PACK/master/TA_Tiberium_Alliances_Battle_Simulator_V2.user.js
  Reference for the STABS battle simulator. **TABS has no license**: neither the script nor the
  upstream repo (Eistee82/ta_simv2) names one, so all rights stay with its authors. NetquiK's pack is
  GPL-3.0, but that only covers his own changes. STABS therefore rewrites the logic; no TABS code is
  copied into Shockr.
