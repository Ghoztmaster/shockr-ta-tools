# Shockr TA Tools

**NL:** Shockr TA Tools — hersteld en uitgebreid. Camp tracker, kill info, speler-status en alliance-verkenning voor C&C Tiberium Alliances.

**DE:** Shockr TA Tools — repariert und erweitert. Camp-Tracker, Kill-Info, Spieler-Status und Allianz-Aufklärung für C&C Tiberium Alliances.

---

## What is this?

A Tampermonkey userscript for [C&C Tiberium Alliances](https://www.tiberiumalliances.com/) that adds:

- **CampTracker** — numbered markers on the world map for nearby camps and outposts
- **KillInfo** — plunder value tooltip on mouseover in battle view
- **PlayerStatus** — alliance base colors by online status (online/away/offline)
- **Alliance Scanner** — automatically scan base layouts and view them online *(planned)*

This is a clean-room rebuild of the original [Shockr Tools](https://shockr.dev) (v4.5.3.6, NetquiK fork), which stopped working after the shockr.dev API went offline and game client updates broke the ClientLib patches.
