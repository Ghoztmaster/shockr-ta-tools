Installation guide for C&C Tiberium Alliances

Wat is dit?

Shockr TA Tools is een browser-uitbreiding die extra functies aan het spel toevoegt. Denk aan gekleurde markers op de kaart, plunder-info bij gevechten, en automatische verkenning van vijandelijke bases voor je alliance.

Het script draait in Tampermonkey — een gratis browser-extensie die kleine programma's (userscripts) in webpagina's kan laden. Je installeert het één keer, en daarna werkt het vanzelf als je het spel opent.

Was ist das?

Shockr TA Tools ist eine Browser-Erweiterung, die dem Spiel zusätzliche Funktionen hinzufügt. Zum Beispiel farbige Markierungen auf der Weltkarte, Beute-Infos im Kampf und automatisches Scannen feindlicher Basen für deine Allianz.

Das Script läuft in Tampermonkey — einer kostenlosen Browser-Erweiterung, die kleine Programme (Userscripts) in Webseiten laden kann. Du installierst es einmal, und danach funktioniert es automatisch wenn du das Spiel öffnest.

What is this?

Shockr TA Tools is a browser extension that adds extra features to the game. Think colored markers on the world map, plunder info in battles, and automatic scanning of enemy bases for your alliance.

The script runs inside Tampermonkey — a free browser extension that can load small programs (userscripts) into web pages. You install it once, and after that it works automatically whenever you open the game.

5 Scanner

Alliance-scanner instellen (optioneel)

Het script kan automatisch vijandelijke bases scannen en delen op een gedeelde website. Zo kan iedereen in de alliance base-layouts bekijken zonder zelf naar elke base te vliegen.

Dit werkt alleen als je alliance-leider je de server-URL en een enrollment-code heeft gegeven.

Typ in de game-chat:

/st config set api.url https://jullie-server-url

Registreer je daarna:

/st register

Er opent een klein popup-venster in het spel. Vul daar de enrollment-code in die je van je alliance hebt gekregen.

🔌
Plugins aan/uit zetten: klik op het schildje (🛡️⚡) linksboven → je ziet knoppen voor elke plugin. Of typ /st status in de game-chat om te zien wat er aan staat.

Allianz-Scanner einrichten (optional)

Das Script kann automatisch feindliche Basen scannen und auf einer gemeinsamen Website teilen. So kann jeder in der Allianz Base-Layouts ansehen, ohne selbst zu jeder Base fliegen zu müssen.

Das funktioniert nur, wenn dein Allianzleiter dir die Server-URL und einen Enrollment-Code gegeben hat.

Tippe im Spiel-Chat:

/st config set api.url https://eure-server-url

Dann registriere dich:

/st register

Es öffnet sich ein kleines Popup-Fenster im Spiel. Gib dort den Enrollment-Code ein, den du von deiner Allianz bekommen hast.

🔌
Plugins ein-/ausschalten: klicke auf das Schildsymbol (🛡️⚡) oben links → du siehst Buttons für jedes Plugin. Oder tippe /st status im Spiel-Chat um zu sehen was aktiv ist.

Set up the alliance scanner (optional)

The script can automatically scan enemy bases and share them on a shared website. This way everyone in the alliance can view base layouts without having to fly to each base themselves.

This only works if your alliance leader has given you the server URL and an enrollment code.

Type in the game chat:

/st config set api.url https://your-server-url

Then register:

/st register

A small popup window opens inside the game. Enter the enrollment code you received from your alliance.

🔌
Toggle plugins on/off: click the shield icon (🛡️⚡) in the top-left → you'll see buttons for each plugin. Or type /st status in the game chat to see what's active.
6 Nieuw · Neu · New

Nieuw in v5.30 en v5.31

Tampermonkey werkt het script zelf bij. Werk nooit bij via Importeren.

v5.31.0 — 29-10-2026

  • Tunnel & POI Analyzer (nieuw): het tunnel-icoon in de Shockr-knop (of /st tunnels) toont per tunnel exit hoeveel alliance-spelers een base binnen 5 velden hebben (5 nodig = actief), wie dat zijn en hoeveel er nog missen. Lage bases in de zone (base level meer dan 5 onder het vereiste tunnellevel) staan erbij als spawn-risico: daardoor spawnen er lage camps in de zone. Alliance-POI's met een real loss van 0/h zijn waardeloos: de bases ernaast kunnen verhuizen. Klik op een rij om de kaart te centreren.
/st config set tpa.players 5 /st config set tpa.range 5 /st config set tpa.guardrange 5 /st config set tpa.spawnmargin 5

v5.30.0 — 29-10-2026

  • Marker-navigator (nieuw): het pin-icoon in de Shockr-knop (of /st markers) toont je kaartmarkers, zoals een Layout-reservering. Klik op een rij om de kaart erop te centreren.
  • Sector HUD: toont weer het midden van het beeld (niet meer je reserveringsmarker). De sector is de richting vanaf het wereldcentrum.
  • Snelle scanners: LayoutScanner en AllianceScanner scannen op de wereldkaart 100 ms per base (2 s in andere views, zonder flikkering).
  • AutoRepair: kan na een aanval op je base ook gebouwen repareren (standaard uit).
  • Tunnel Info: de rode cirkel is dekkend en 3 px breed; kleur en breedte zijn instelbaar.
/st config set autorepair.buildings true /st config set tunnel.color #ff3600 /st config set tunnel.width 3
💡
Alle commando's en instellingen staan ook in het spel: typ /st help.

Problemen oplossen

Ik zie geen [ST]-melding in de chat

Controleer of Tampermonkey aan staat: klik op het TM-icoontje rechtsboven in je browser. Shockr TA Tools moet in de lijst staan met een groen vinkje.

Chrome: klik rechts op het TM-icoontje → Extensie beheren → Gebruikersscripts toestaan moet aan staan.

Herlaad daarna de game met F5.

Geen markers op de wereldkaart

CampTracker heeft even nodig om de kaart te scannen. Wacht 10–15 seconden na het laden en scroll/zoom op de wereldkaart.

Check of de plugin aanstaat: typ /st status in de game-chat. CampTracker moet op enabled staan.

Alliance-bases zijn niet gekleurd

PlayerStatus heeft ~30 seconden nodig om online-status op te halen. Scroll een stukje op de kaart, dan refreshen de markers.

Scanner meldt "no server configured"

Je hebt de server-URL nog niet ingesteld. Vraag je alliance-leider om de URL en enrollment-code, en volg stap 5 hierboven.

Script conflicteert met een ander userscript

Sommige andere TA-scripts kunnen botsen met Shockr. Probeer in Tampermonkey alle andere TA-scripts tijdelijk uit te zetten, herlaad de game, en zet ze één voor één weer aan om te vinden welk script het conflict veroorzaakt.

Meld het bij je alliance-leider met de foutmelding uit de console (F12 → Console).

Ik wil het script verwijderen

Klik op het TM-icoontje → Dashboard → zoek "Shockr TA Tools" → klik op het prullenbakje. Herlaad daarna de game.

Probleme lösen

Ich sehe keine [ST]-Meldung im Chat

Prüfe ob Tampermonkey aktiv ist: klicke auf das TM-Icon oben rechts im Browser. Shockr TA Tools muss in der Liste mit einem grünen Häkchen stehen.

Chrome: Rechtsklick auf das TM-Icon → Erweiterung verwalten → Zugriff auf Datei-URLs erlauben muss aktiviert sein.

Danach das Spiel mit F5 neu laden.

Keine Markierungen auf der Weltkarte

CampTracker braucht einen Moment um die Karte zu scannen. Warte 10–15 Sekunden nach dem Laden und scrolle/zoome auf der Weltkarte.

Prüfe ob das Plugin aktiv ist: tippe /st status im Spiel-Chat. CampTracker muss auf enabled stehen.

Allianz-Basen sind nicht eingefärbt

PlayerStatus braucht ~30 Sekunden um den Online-Status abzurufen. Scrolle ein Stück auf der Karte, dann werden die Markierungen aktualisiert.

Scanner meldet "no server configured"

Du hast die Server-URL noch nicht eingestellt. Frage deinen Allianzleiter nach URL und Enrollment-Code, und folge Schritt 5 oben.

Script kollidiert mit einem anderen Userscript

Manche anderen TA-Scripts können mit Shockr kollidieren. Versuche in Tampermonkey alle anderen TA-Scripts vorübergehend zu deaktivieren, lade das Spiel neu, und aktiviere sie einzeln wieder um den Konflikt zu finden.

Melde es deinem Allianzleiter mit der Fehlermeldung aus der Konsole (F12 → Console).

Ich möchte das Script entfernen

Klicke auf das TM-Icon → Dashboard → suche "Shockr TA Tools" → klicke auf den Papierkorb. Danach das Spiel neu laden.

Troubleshooting

I don't see an [ST] message in chat

Check that Tampermonkey is active: click the TM icon in the top-right of your browser. Shockr TA Tools should be listed with a green checkmark.

Chrome: right-click the TM icon → Manage extension → Allow access to file URLs must be turned on.

Then reload the game with F5.

No markers on the world map

CampTracker needs a moment to scan the map. Wait 10–15 seconds after loading and scroll/zoom on the world map.

Check if the plugin is active: type /st status in the game chat. CampTracker should say enabled.

Alliance bases are not colored

PlayerStatus needs ~30 seconds to fetch online status. Scroll around on the map a bit, then the markers will refresh.

Scanner says "no server configured"

You haven't set the server URL yet. Ask your alliance leader for the URL and enrollment code, and follow step 5 above.

Script conflicts with another userscript

Some other TA scripts can clash with Shockr. Try disabling all other TA scripts in Tampermonkey, reload the game, and re-enable them one by one to find which script causes the conflict.

Report it to your alliance leader with the error message from the console (F12 → Console).

I want to remove the script

Click the TM icon → Dashboard → find "Shockr TA Tools" → click the trash icon. Then reload the game.
